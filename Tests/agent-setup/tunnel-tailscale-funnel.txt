Tailscale Funnel (recommended)
preservesHost: true
detectionHeader: Tailscale-Funnel-Request

commands:
tailscale funnel --bg --https=443 --set-path /r/q7Zk2vN4bXwP9sL1mT6hYa http://127.0.0.1:47616/r/q7Zk2vN4bXwP9sL1mT6hYa
tailscale funnel --bg --https=443 --set-path /.well-known/oauth-protected-resource/r/q7Zk2vN4bXwP9sL1mT6hYa http://127.0.0.1:47616/.well-known/oauth-protected-resource/r/q7Zk2vN4bXwP9sL1mT6hYa
tailscale funnel --bg --https=443 --set-path /.well-known/oauth-authorization-server/r/q7Zk2vN4bXwP9sL1mT6hYa http://127.0.0.1:47616/.well-known/oauth-authorization-server/r/q7Zk2vN4bXwP9sL1mT6hYa
tailscale funnel --bg --https=443 --set-path /.well-known/openid-configuration/r/q7Zk2vN4bXwP9sL1mT6hYa http://127.0.0.1:47616/.well-known/openid-configuration/r/q7Zk2vN4bXwP9sL1mT6hYa

off:
tailscale funnel --https=443 --set-path /r/q7Zk2vN4bXwP9sL1mT6hYa off
tailscale funnel --https=443 --set-path /.well-known/oauth-protected-resource/r/q7Zk2vN4bXwP9sL1mT6hYa off
tailscale funnel --https=443 --set-path /.well-known/oauth-authorization-server/r/q7Zk2vN4bXwP9sL1mT6hYa off
tailscale funnel --https=443 --set-path /.well-known/openid-configuration/r/q7Zk2vN4bXwP9sL1mT6hYa off

steps:
1. Install Tailscale on this Mac and sign in.
2. In the Tailscale admin console, turn on MagicDNS and HTTPS certificates, and add the funnel node attribute to your tailnet policy.
3. Run the commands in Terminal. Each adds one of the Remote Access paths to Funnel's port; everything else on that port, such as another app's tunnel, stays as it is.
4. Paste your Mac's Funnel address, such as https://my-mac.tail1234.ts.net in step 3. Public DNS can take about 10 minutes the first time.
5. To turn it off, run the off commands below them. They remove only these paths.

notes:
- TLS ends on this Mac, inside Tailscale, so the relays in between can't read the traffic.
- Funnel keeps the public hostname in Host, so it must match Address.
- Tailscale Serve isn't enough: cloud agents aren't on your tailnet.
- Funnel keeps running in the background, even after a restart, until you turn it off.
- claude.ai and ChatGPT only connect to port 443, so apps on this Mac share it by path: Tailscale sends these paths here and every other path where it went before.
- The paths include the secret path. After Reset Path…, the page shows the commands that move Funnel to the new one.
